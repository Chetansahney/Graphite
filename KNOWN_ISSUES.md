## Theme Summary

Issues from the last 30 days cluster into the following themes:

### 🔴 Build / Run Locally Failures
Problems that prevent the project from building or starting in a local development environment.

| Issue | Summary |
|-------|---------|
| [#3939](https://github.com/GraphiteEditor/Graphite/issues/3939) | **`cargo run` fails** — `CARGO_BUILD_TARGET=wasm32-unknown-unknown` leaks into the `rustc_codegen_spirv` build during `wasm-pack build`, causing a dylib build failure. Affects anyone following the standard dev-setup guide. |
| [#3821](https://github.com/GraphiteEditor/Graphite/issues/3821) ✅ | **Dev server EACCES on Windows** — `npm`/Vite dev server crashes with EACCES if port 8080 is already in use. Now fixed. |
| [#3895](https://github.com/GraphiteEditor/Graphite/issues/3895) | **Flatpak RC4 won't launch** — The RC4 release Flatpak package fails to launch on Linux. |
